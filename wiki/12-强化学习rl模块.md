# 12 · 强化学习（`tinytorch.rl`）

`tinytorch.rl` 提供一组教学友好的强化学习组件，用来演示从环境交互、经验采样、轨迹估计到深度强化学习算法更新的完整流程。相关源码位于 `tinytorch/rl/`。

> 当前实现聚焦纯 Python、小规模、离散动作空间场景。它适合理解 RL 算法机制和验证小实验，不适合高吞吐并行采样或大规模训练。

## 12.1 模块结构

```text
tinytorch/rl/
├── spaces.py   # Space / Discrete / Box / MultiDiscrete
├── envs.py     # Env / VectorEnv / GridWorldEnv
├── replay.py   # Transition / ReplayBuffer / PrioritizedReplayBuffer / RolloutBuffer
└── agents.py   # QLearning / DQN / DoubleDQN / REINFORCE / Actor-Critic / PPO
```

通过下面方式导入常用能力：

```python
from tinytorch.rl import (
    GridWorldEnv,
    ReplayBuffer,
    PrioritizedReplayBuffer,
    RolloutBuffer,
    QLearningAgent,
    DQNAgent,
    PPOAgent,
)
```

## 12.2 核心概念

强化学习和监督学习最大的区别在于：训练样本不是一次性给定的静态数据集，而是智能体通过与环境交互逐步生成的。

典型循环如下：

```text
state = env.reset()

while not done:
    action = agent.select_action(state)
    next_state, reward, done, info = env.step(action)
    agent.learn(...)
    state = next_state
```

`tinytorch.rl` 将这个过程拆成几类基础组件：

| 组件 | 作用 |
|------|------|
| `Space` | 描述动作或观测的合法取值范围 |
| `Env` | 环境接口，提供 `reset()` 和 `step(action)` |
| `ReplayBuffer` | off-policy 算法使用的经验回放 |
| `RolloutBuffer` | on-policy 算法使用的轨迹缓存 |
| `Agent` | 策略、价值估计和参数更新逻辑 |

## 12.3 空间定义（spaces）

### 12.3.1 `Discrete`

离散空间，取值为 `0 ~ n-1`，常用于分类动作。

```python
from tinytorch.rl import Discrete

space = Discrete(4)
action = space.sample()
assert space.contains(action)
```

### 12.3.2 `Box`

连续向量空间，常用于连续观测。

```python
from tinytorch.rl import Box

obs_space = Box(low=-1.0, high=1.0, shape=(3,))
obs = obs_space.sample()
assert obs_space.contains(obs)
```

当前 `Box` 支持一维向量空间，适合教学示例和小型 MLP 输入。

### 12.3.3 `MultiDiscrete`

多离散空间，每个维度都有独立的取值范围。

```python
from tinytorch.rl import MultiDiscrete

space = MultiDiscrete([2, 3])
action = space.sample()   # 例如 [1, 2]
```

## 12.4 环境接口（envs）

### 12.4.1 `Env`

`Env` 是环境基类，约定两个核心方法：

```python
class MyEnv(Env):
    def reset(self):
        ...

    def step(self, action):
        # return next_state, reward, done, info
        ...
```

其中 `step()` 返回四元组：

| 返回值 | 说明 |
|--------|------|
| `next_state` | 下一状态 |
| `reward` | 当前动作获得的奖励 |
| `done` | episode 是否结束 |
| `info` | 调试信息字典 |

### 12.4.2 `GridWorldEnv`

`GridWorldEnv` 是项目内置的二维网格环境，动作为：

| 动作 | 含义 |
|------|------|
| `0` | 上 |
| `1` | 右 |
| `2` | 下 |
| `3` | 左 |

示例：

```python
from tinytorch.rl import GridWorldEnv

env = GridWorldEnv(
    width=4,
    height=4,
    start=(0, 0),
    goal=(3, 3),
    obstacles=[(1, 1), (2, 1)],
)

state = env.reset()
next_state, reward, done, info = env.step(1)
print(env.render())
```

`GridWorldEnv` 还提供两个状态转换方法：

| 方法 | 说明 |
|------|------|
| `state_index(state=None)` | 将 `(x, y)` 映射为离散索引 |
| `state_vector(state=None)` | 返回归一化坐标向量，便于 DQN / PPO 输入网络 |

### 12.4.3 `VectorEnv`

`VectorEnv` 用一个对象顺序管理多个环境实例，便于收集多条环境轨迹。

```python
from tinytorch.rl import GridWorldEnv, VectorEnv

envs = VectorEnv([
    lambda: GridWorldEnv(width=4, height=4),
    lambda: GridWorldEnv(width=4, height=4),
])

states = envs.reset()
next_states, rewards, dones, infos = envs.step([1, 2])
```

它不使用多进程，主要用于教学和小规模采样。

## 12.5 经验回放与轨迹缓存

### 12.5.1 `Transition`

`Transition` 是单步交互样本：

```python
Transition(state, action, reward, next_state, done)
```

其中 `state` 和 `next_state` 通常是 Python 数值列表，便于转换为 `NdArray` / `Tensor`。

### 12.5.2 `ReplayBuffer`

固定容量经验回放，用于 DQN / Double DQN 等 off-policy 算法。

```python
from tinytorch.rl import ReplayBuffer

buffer = ReplayBuffer(capacity=10000)
buffer.push([0.0, 0.0], action=1, reward=1.0, next_state=[1.0, 0.0], done=False)
batch = buffer.sample(batch_size=32)
```

### 12.5.3 `PrioritizedReplayBuffer`

优先级经验回放会让 TD error 更大的样本更容易被采到。

```python
from tinytorch.rl import PrioritizedReplayBuffer

buffer = PrioritizedReplayBuffer(capacity=10000, alpha=0.6, beta=0.4)
buffer.push(state, action, reward, next_state, done, priority=1.0)
sample = buffer.sample(batch_size=32)

# 学习后用新的 TD error 更新优先级
buffer.update_priorities(sample.indices, td_errors)
```

在 `DQNAgent.learn()` 中，如果传入的是 `PrioritizedReplayBuffer`，会自动根据 TD error 调用 `update_priorities()`。

### 12.5.4 `RolloutBuffer`

`RolloutBuffer` 用于 PPO / Actor-Critic 这类 on-policy 算法，支持 discounted return 和 GAE advantage。

```python
from tinytorch.rl import RolloutBuffer

rollout = RolloutBuffer()
rollout.add(state, action, reward, next_state, done, value=0.3, log_prob=-0.7)
rollout.compute_returns_and_advantages(gamma=0.99, gae_lambda=0.95)
```

关键字段：

| 字段 | 说明 |
|------|------|
| `steps` | 原始轨迹步骤 |
| `returns` | 每一步的目标回报 |
| `advantages` | 每一步的优势估计 |

## 12.6 算法与 Agent

### 12.6.1 `QLearningAgent`

表格 Q-learning，适合状态/动作空间很小的离散环境。

```python
from tinytorch.rl import GridWorldEnv, QLearningAgent

env = GridWorldEnv(width=4, height=4)
agent = QLearningAgent(action_size=env.action_space.n, learning_rate=0.3, gamma=0.95)

for _ in range(100):
    total_reward, steps = agent.train_episode(env)
```

核心更新公式：

```text
Q(s, a) ← Q(s, a) + lr * (r + gamma * max_a' Q(s', a') - Q(s, a))
```

### 12.6.2 `DQNAgent`

DQN 使用神经网络近似 Q 函数。网络输入状态向量，输出每个动作的 Q 值。

```python
from tinytorch.nn import Linear, ReLU, Sequential
from tinytorch.ml.optimizers import SGD
from tinytorch.rl import DQNAgent

q_network = Sequential(
    Linear(2, 16),
    ReLU(),
    Linear(16, 4),
)

agent = DQNAgent(
    q_network=q_network,
    optimizer=SGD(q_network.parameters(), learning_rate=0.01),
    state_dim=2,
    action_size=4,
    batch_size=32,
)
```

常用方法：

| 方法 | 说明 |
|------|------|
| `select_action(state, training=True)` | epsilon-greedy 选动作 |
| `remember(state, action, reward, next_state, done)` | 写入 replay |
| `learn()` | 从 replay 采样并更新一次网络 |
| `train_step(env, state=None, state_encoder=None)` | 与环境交互一步并尝试学习 |
| `sync_target_network()` | 硬同步 target network |
| `soft_update_target_network(tau=0.005)` | 软更新 target network |

### 12.6.3 `DoubleDQNAgent`

Double DQN 继承自 `DQNAgent`，区别在于 Bellman bootstrap：

```text
普通 DQN:
target = r + gamma * max_a Q_target(s', a)

Double DQN:
a* = argmax_a Q_online(s', a)
target = r + gamma * Q_target(s', a*)
```

这可以缓解 `max` 操作导致的 Q 值过估计。

### 12.6.4 `PolicyGradientAgent`（REINFORCE）

REINFORCE 直接优化策略网络。策略网络输入状态，输出动作 logits。

```python
from tinytorch.rl import PolicyGradientAgent

agent = PolicyGradientAgent(
    policy_network=policy_network,
    optimizer=optimizer,
    state_dim=2,
    action_size=4,
    gamma=0.99,
)

loss = agent.learn_trajectory(trajectory)
```

当前实现使用 `CrossEntropyLoss` 近似 `-log π(a|s)`，再用 return 作为权重。

### 12.6.5 `ActorCriticAgent`

Actor-Critic 同时训练策略网络和价值网络：

| 网络 | 作用 |
|------|------|
| policy network | 输出动作 logits |
| value network | 输出状态价值 `V(s)` |

可以直接用轨迹更新：

```python
metrics = agent.learn_trajectory(trajectory)
```

也可以使用 `RolloutBuffer`：

```python
rollout.compute_returns_and_advantages(gamma=0.99)
metrics = agent.learn_rollout(rollout)
```

### 12.6.6 `PPOAgent`

PPO 在 Actor-Critic 基础上加入 clipped policy update，避免单次策略更新过大。

```python
metrics = agent.learn_trajectory(trajectory, old_action_probs)
```

使用 `RolloutBuffer` 时，`log_prob` 会被转换为旧策略动作概率：

```python
rollout.compute_returns_and_advantages(gamma=0.99, gae_lambda=0.95)
metrics = agent.learn_rollout(rollout)
```

当前 PPO 实现适合离散动作空间，连续控制分布暂未覆盖。

## 12.8 选择哪个算法

| 场景 | 推荐 |
|------|------|
| 小型离散状态空间 | `QLearningAgent` |
| 离散动作 + 神经网络 Q 函数 | `DQNAgent` |
| DQN 训练中 Q 值明显偏高 | `DoubleDQNAgent` |
| 想理解策略梯度基本原理 | `PolicyGradientAgent` |
| 需要同时学习策略和值函数 | `ActorCriticAgent` |
| on-policy 稳定策略更新 | `PPOAgent` |

## 12.9 当前限制

- 纯 Python 实现，采样和神经网络训练都不追求性能；
- 策略梯度类算法当前聚焦离散动作空间；
- `VectorEnv` 是顺序执行，不是多进程并行采样；
- PPO 是教学版实现，未覆盖 mini-batch 多 epoch、entropy bonus、value clipping 等工程细节；
- `PrioritizedReplayBuffer` 使用线性扫描采样，不适合大容量高频训练；
- 连续控制算法如 DDPG / TD3 / SAC 尚未实现。

## 12.10 与其他模块的关系

`tinytorch.rl` 复用项目已有的底层能力：

| 依赖模块 | 用途 |
|----------|------|
| `tinytorch.ndarr` | 状态向量、目标值、网络输入输出的底层数组 |
| `tinytorch.autograd` | 策略网络 / Q 网络 / value 网络的反向传播 |
| `tinytorch.nn` | 构建 policy、Q、value 网络 |
| `tinytorch.ml.optimizers` | 使用 `SGD` / `Adam` 更新参数 |
| `tinytorch.ml.losses` | 使用 `MSELoss` / `CrossEntropyLoss` 构造 RL 目标 |

因此，强化学习模块不是独立框架，而是 tinyTorch 现有深度学习能力之上的算法层。
