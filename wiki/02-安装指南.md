# 02 · 安装指南

本文介绍如何在本地安装、配置和验证 tinyTorch。因为它是一个**纯 Python、零运行时依赖**的项目，安装过程非常简单。

## 2.1 环境要求

| 项 | 要求 | 说明 |
|----|------|------|
| Python | `>= 3.7` | 官方 CPython 即可；不依赖特定解释器 |
| 操作系统 | Linux / macOS / Windows | 无平台特定代码 |
| 运行时依赖 | **无** | `requirements.txt` 明确声明无运行时依赖 |
| 开发依赖 | `pytest>=6.0`、`pytest-cov>=2.10`、`ruff>=0.4.0` | 仅开发/测试/代码风格检查用 |

> 注意：由于使用 Python 纯标准库，**启动和导入速度非常快**，但大规模矩阵运算性能远低于 NumPy / PyTorch。

## 2.2 安装步骤

### 方式 A：从源码以可编辑方式安装（推荐）

```bash
# 1. 克隆仓库
git clone <repository-url>
cd tinyTorch

# 2. （可选）创建并激活虚拟环境
python -m venv venv
source venv/bin/activate          # macOS / Linux
# venv\Scripts\activate           # Windows

# 3. 可编辑安装（修改源码立刻生效）
pip install -e .
```

### 方式 B：同时安装开发依赖

如果你准备跑测试、贡献代码或做代码风格检查：

```bash
pip install -e ".[dev]"
```

`.[dev]` 会额外安装 `pytest`、`pytest-cov`、`ruff`，这些仅在开发阶段使用。

### 方式 C：使用 `setup.py`

```bash
python setup.py develop
```

效果等同于 `pip install -e .`，但更建议使用 pip。

## 2.3 验证安装

### 方法 1：导入并打印版本

```bash
python -c "import tinytorch; print(tinytorch.__version__)"
```

期望输出类似：

```
0.1.0
```

### 方法 2：运行内置快速自测

```bash
python examples/basic/quick_test.py
```

该脚本会构建一个小型网络、做一次前向 + 反向传播，若无异常则说明核心模块工作正常。

### 方法 3：跑单元测试

安装了 dev 依赖后：

```bash
pytest
```

或者使用项目自带的脚本（该脚本会自动检测并安装缺失的 `pytest`，再转发到 `pytest tests/`）：

```bash
python run_tests.py              # 运行全部测试，默认 -v 详细输出
python run_tests.py test_tensor  # 只跑 tests/test_tensor.py
python run_tests.py -h           # 查看帮助
```

当所有用例通过时，说明你的环境完全 OK。

## 2.4 目录结构与安装产物

以可编辑方式安装后，Python 导入路径会指向源码目录，便于调试：

```text
tinyTorch/
├── tinytorch/          ← 源码（pip 以 egg-link 方式指向这里）
├── tinytorch.egg-info/ ← 安装元信息（自动生成）
├── examples/           ← 可运行示例
├── tests/              ← 单元测试
├── docs/               ← 教程文档
└── wiki/               ← 本 wiki 文档
```

## 2.5 卸载

```bash
pip uninstall tinytorch
```

如果使用了虚拟环境，也可以直接删除整个虚拟环境目录。

## 2.6 常见安装问题

### Q1：`pip install -e .` 报错 `ModuleNotFoundError: No module named 'setuptools'`

升级 pip 与 setuptools：

```bash
pip install --upgrade pip setuptools wheel
```

### Q2：Python 版本过低

tinyTorch 需要 Python 3.7+。可通过下列命令确认：

```bash
python --version
```

若版本过低，建议使用 `pyenv` / `conda` 安装更高版本。

### Q3：在 Windows 下运行 shell 命令失败

本文示例中的命令使用 bash 语法。在 Windows PowerShell 下，激活虚拟环境请使用：

```powershell
venv\Scripts\Activate.ps1
```

### Q4：`pytest` 找不到测试

确保已安装 dev 依赖，并在项目根目录执行：

```bash
pip install -e ".[dev]"
pytest
```

`pyproject.toml` 中已配置 `testpaths = ["tests"]`。

### Q5：提示找不到 `ruff` 或 `pytest`

这两个工具只在 dev 依赖中。先安装：

```bash
pip install -e ".[dev]"
```

更多问题参见 [10 · 常见问题解答 (FAQ)](./10-常见问题解答FAQ.md)。

## 2.7 推荐开发配置

- **编辑器**：VSCode / PyCharm 任选其一。
- **代码风格检查**（项目在 `pyproject.toml` 的 `[tool.ruff.lint]` 中启用了 `E/W/F/I/UP/B/SIM/RUF` 一组规则，`line-length = 120`，目标 Python 版本 3.7）：

```bash
ruff check tinytorch tests        # 检查风格与简单缺陷
ruff check --fix tinytorch tests  # 自动修复可安全修复的问题
```

- **测试覆盖率**（`pyproject.toml` 中已配置 `source = ["tinytorch"]`，会忽略 `tests/` 与 `examples/`）：

```bash
pytest --cov=tinytorch --cov-report=term-missing
```
