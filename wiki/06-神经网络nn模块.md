# 06 · 神经网络模块（`tinytorch.nn`）

`tinytorch.nn` 构建在 `autograd` 之上，提供与 PyTorch 风格接近的模型抽象：`Module` / `Parameter` / 容器 / 各类层 / 初始化工具。本文对应源码：

- `tinytorch/nn/module.py` — `Module` 基类
- `tinytorch/nn/parameter.py` — `Parameter` 类
- `tinytorch/nn/container.py` — `Sequential` / `ModuleList`
- `tinytorch/nn/init.py` — 参数初始化
- `tinytorch/nn/layers/` — 各种具体层

## 6.1 模块总览

| 子模块 / 类 | 作用 |
|--------------|------|
| `Module` | 层 / 模型基类，管理子模块、参数、缓冲区、训练模式 |
| `Parameter` | `Tensor` 子类，默认 `requires_grad=True`，用于表示可训练参数 |
| `Sequential` | 顺序容器，按添加顺序前向传播 |
| `ModuleList` | 列表容器，**不**实现 `forward`，由外部自行组织 |
| `init` | 参数初始化函数（Xavier / Kaiming / 正态 / 均匀 / 常数 / 0/1 …） |
| `layers.*` | 具体层：`Linear` / `Conv2d` / `Embedding` / `RNN` / `LSTM` / `GRU` / `MultiHeadAttention` / `LayerNorm` / `Dropout` / 激活 |

## 6.2 `Module` 基类

### 6.2.1 核心设计：赋值即注册

`Module.__setattr__` 会自动把赋给实例属性的 `Module` / `Parameter` 登记到内部注册表：

```python
from tinytorch.nn import Module, Parameter, Linear
from tinytorch.autograd import Tensor
from tinytorch.ndarr import NdArray


class MyNet(Module):
    def __init__(self):
        super().__init__()
        self.fc1 = Linear(10, 20)                        # → _modules['fc1']
        self.weight = Parameter(NdArray.randn((5, 10)))  # → _parameters['weight']
        self.register_buffer(
            'running_mean',
            Tensor(NdArray.zeros((10,)), requires_grad=False)
        )                                                # → _buffers['running_mean']
```

核心行为（实现位于 `Module.__setattr__`）：

- `Module` 实例 → 记入 `_modules`，同时清理 `_parameters` / `_buffers` 里同名项；
- `Parameter` 实例 → 记入 `_parameters`，同时清理 `_modules` / `_buffers`；
- `Tensor` 实例**不会**被自动注册为 buffer —— buffer 必须显式调用 `register_buffer`；
- 以下划线 `_` 开头的属性名（如 `_modules` 自己）会走普通 `object.__setattr__`，不触发注册逻辑。

### 6.2.2 常用属性

| 属性 | 说明 |
|------|------|
| `_modules: Dict[str, Module]` | 子模块表 |
| `_parameters: Dict[str, Parameter]` | 本模块直接拥有的参数 |
| `_buffers: Dict[str, Tensor]` | 不参与梯度更新的状态张量 |
| `training: bool` | 训练 / 评估模式开关，默认 `True` |
| `name: str` | 模块名，未传时为类名 |

### 6.2.3 常用方法

| 方法 | 作用 |
|------|------|
| `forward(*inputs)` | **抽象方法**，子类必须实现 |
| `__call__(*inputs, **kwargs)` | 调 `forward`，等价于 `module(x)` |
| `parameters(recursive=True)` | 返回所有参数（递归到子模块） |
| `named_parameters(prefix='', recursive=True)` | 产出 `(完整名称, Parameter)` |
| `named_buffers(prefix='', recursive=True)` | 产出 `(完整名称, Tensor)` |
| `modules()` / `named_modules(prefix='')` | 递归遍历所有模块 |
| `train(mode=True)` / `eval()` | 切换训练 / 评估模式；会递归作用到所有子模块 |
| `zero_grad()` | 清空所有参数的梯度 |
| `register_module(name, module)` | 手动注册 / 移除（传 `None` 移除）子模块 |
| `register_parameter(name, param)` | 手动注册 / 移除参数 |
| `register_buffer(name, tensor)` | 手动注册 / 移除缓冲区 |
| `state_dict()` | 返回扁平状态字典（键为完整路径，值含 `kind`/`value`/`shape`/`dtype`/`requires_grad`） |
| `load_state_dict(state_dict, strict=True)` | 从状态字典加载参数 / 缓冲区；`strict=True` 时缺失/多余键会抛 `KeyError`，否则返回 `{'missing_keys': [...], 'unexpected_keys': [...]}` |
| `to_dict()` | 模块的可序列化表示（含 `class` / `name` / `training` / `state_dict`） |

### 6.2.4 `state_dict()` 的数据结构

```python
{
    'fc1.weight': {
        'kind': 'parameter',
        'value': [[...]],           # NdArray.to_list() 结果
        'shape': (20, 10),
        'dtype': 'float32',
        'requires_grad': True,
    },
    'fc1.bias': { ... },
    'running_mean': {
        'kind': 'buffer',
        ...
    },
}
```

`Module.state_dict()` 是**扁平**结构（键带 `.` 分隔的完整路径）；`Model.save()` 也是基于它序列化的。

## 6.3 `Parameter` 类

`Parameter` 是 `Tensor` 的子类，差别在于：

- 默认 `requires_grad=True`；
- 提供 `to_dict()` / `from_dict()` 两个**类自身级别**的序列化方法（注意：`Module.state_dict` 用的是 `_tensor_state`，两套序列化格式略有不同，但都能描述参数）。

典型用法：

```python
from tinytorch.nn import Parameter
from tinytorch.ndarr import NdArray

weight = Parameter(NdArray.randn((10, 5)), name='weight')
bias = Parameter(NdArray.zeros((5,)), name='bias')

# 查看
print(weight)           # Parameter('weight', shape=(10, 5), requires_grad=True)

# 清梯度（继承自 Tensor.clear_grad）
weight.clear_grad()
```

## 6.4 参数初始化（`nn.init`）

`tinytorch/nn/init.py` 提供 PyTorch 风格的初始化函数。**按后缀区分语义**：

- 带下划线后缀 `_` 的是**原地**操作（`uniform_` / `normal_` / `constant_` 等）；
- 无后缀的 `uniform(a, b, shape, dtype)` 是**工厂函数**，返回新的 `NdArray`。

### 6.4.1 可用函数一览

| 函数 | 签名 | 行为 |
|------|------|------|
| `uniform(a, b, shape, dtype='float32')` | 工厂 | 返回 `U(a, b)` 的新 `NdArray` |
| `uniform_(tensor, a=0.0, b=1.0)` | 原地 | 用 `U(a, b)` 填充 |
| `normal_(tensor, mean=0.0, std=1.0)` | 原地 | 用 `N(mean, std²)` 填充 |
| `constant_(tensor, val)` | 原地 | 全部置为常数 |
| `zeros_(tensor)` | 原地 | `constant_(tensor, 0.0)` |
| `ones_(tensor)` | 原地 | `constant_(tensor, 1.0)` |
| `xavier_uniform_(tensor, gain=1.0)` | 原地 | Glorot 均匀：`U(-a, a)`，`a = gain * sqrt(6/(fan_in+fan_out))` |
| `xavier_normal_(tensor, gain=1.0)` | 原地 | Glorot 正态：`N(0, std²)`，`std = gain * sqrt(2/(fan_in+fan_out))` |
| `kaiming_uniform_(tensor, a=0, mode='fan_in', nonlinearity='leaky_relu')` | 原地 | He 均匀，`std = gain / sqrt(fan)` |
| `kaiming_normal_(tensor, a=0, mode='fan_in', nonlinearity='leaky_relu')` | 原地 | He 正态 |
| `calculate_gain(nonlinearity='linear')` | 工具 | 返回增益因子，支持 `'linear'` / `'relu'` / `'leaky_relu'` / `'tanh'` / `'sigmoid'` |

**别名**（直接等于上面的函数）：

- `glorot_uniform_` = `xavier_uniform_`
- `glorot_normal_` = `xavier_normal_`
- `he_uniform_` = `kaiming_uniform_`
- `he_normal_` = `kaiming_normal_`

### 6.4.2 fan_in / fan_out 计算规则

由 `_calculate_fan_in_and_fan_out(tensor)` 计算，适配多种常见权重形状：

| 张量维度 | fan_in | fan_out |
|----------|--------|---------|
| 1D（如偏置） | `dims[0]` | `dims[0]` |
| 2D（全连接权重 `(out, in)`） | `dims[1]` | `dims[0]` |
| ≥3D（卷积核 `(out, in, k_h, k_w, ...)`） | `dims[1] * 感受野大小` | `dims[0] * 感受野大小` |

### 6.4.3 使用示例

```python
from tinytorch.nn import init
from tinytorch.ndarr import NdArray

w = NdArray.zeros((20, 10))
init.kaiming_uniform_(w, nonlinearity='relu')   # 就地填充

b = NdArray.zeros((20,))
init.zeros_(b)
```

## 6.5 容器：`Sequential` / `ModuleList`

### 6.5.1 `Sequential`

按添加顺序依次 `forward`：

```python
from tinytorch.nn import Sequential, Linear, ReLU

net = Sequential(
    Linear(10, 20),
    ReLU(),
    Linear(20, 5),
)

# 动态追加
net.add(ReLU())                     # 自动取一个不冲突的层名
print(len(net))                     # 4
print(net[0])                       # 通过索引访问
for layer in net:                   # 可迭代
    print(layer)
```

`Sequential(*layers)` 会自动为每层生成 `layer_0`、`layer_1`、… 的子模块名；若 `add` 时指定的 `name` 已存在，会递增后缀避免冲突。

### 6.5.2 `ModuleList`

不定义 `forward`（调用会抛 `NotImplementedError`），用于需要自行组织前向流程的场景：

```python
from tinytorch.nn import Module, ModuleList, Linear

class StackedResidual(Module):
    def __init__(self, dim, depth):
        super().__init__()
        self.blocks = ModuleList([Linear(dim, dim) for _ in range(depth)])

    def forward(self, x):
        for block in self.blocks:
            x = x + block(x)           # 残差
        return x
```

## 6.6 基础层：`Linear` 与激活

### 6.6.1 `Linear`

```python
Linear(in_features, out_features, use_bias=True, name=None)
```

- 权重形状 `(out_features, in_features)`，用 Kaiming 均匀分布初始化（针对 ReLU）；
- 偏置形状 `(out_features,)`，初始化为 0；若 `use_bias=False` 则 `self.bias is None`；
- `forward` 同时支持 **2D `(batch, in_features)`** 与 **3D `(batch, seq_len, in_features)`**（3D 时内部先 `reshape` 到 2D 再做线性变换）；其他维度会抛 `ValueError`；
- 暴露 `reset_parameters()` 方法允许重新初始化。

### 6.6.2 激活层

`tinytorch/nn/layers/activation.py` 提供四个激活层，无参数（`LeakyReLU` 除外）：

| 类 | 公式 | 备注 |
|----|------|------|
| `ReLU()` | `max(0, x)` | — |
| `Sigmoid()` | `1 / (1 + exp(-x))` | 内部做极端值钳位（见 `NdArray.sigmoid`） |
| `Tanh()` | `math.tanh(x)` | — |
| `LeakyReLU(negative_slope=0.01)` | `max(slope*x, x)` | 唯一带参数的激活层 |

实现上，前三个类共用基类 `_SimpleActivation`：只需指定 `_op_name`（如 `'relu'`），`forward` 自动去调 `Tensor` 上同名方法。

## 6.7 归一化与正则化

### 6.7.1 `LayerNorm`

```python
LayerNorm(normalized_shape, eps=1e-5, elementwise_affine=True, name=None)
```

- `normalized_shape`：对输入的**最后若干个维度**做归一化，维度必须与输入末尾对齐，否则抛 `ValueError`；传 `int` 会自动包成单元素元组；
- `elementwise_affine=True` 时创建 `weight`（全 1）与 `bias`（全 0）；关闭时 `self.weight = self.bias = None`；
- 公式：`y = (x - mean) / sqrt(var + eps) * weight + bias`，`mean` / `var` 都是在 `normalized_shape` 对应的轴上求平均；
- 实现中方差使用 `((x - mean) ** 2).mean(axis=..., keepdims=True)` 的"有偏"估计（分母为 n，不是 n-1）。

### 6.7.2 `Dropout`

```python
Dropout(p=0.5, name=None)
```

- `p` 必须在 `[0, 1)`，否则抛 `ValueError`；
- 仅在**训练模式**（`self.training=True`）且 `p > 0` 时生效；评估模式下直接透传输入；
- 采用反向缩放（inverted dropout）：保留元素乘 `1 / (1 - p)`，丢弃元素乘 0；
- 掩码通过 `NdArray.uniform(0, 1, ...)` 现场生成，随机源走 `tinytorch.utils.random`。

## 6.8 嵌入与卷积

### 6.8.1 `Embedding`

```python
Embedding(num_embeddings, embedding_dim, padding_idx=None, name=None)
```

- `weight` 初始化为 `NdArray.randn((num_embeddings, embedding_dim))`；
- `padding_idx` 必须在 `[0, num_embeddings)`，否则抛 `ValueError`；一旦指定，对应行在初始化后会被强制置 0；
- 前向调用 `autograd.ops.nn.EmbeddingLookup`，输入形状为整数索引 `(*batch_shape,)`，输出形状 `(*batch_shape, embedding_dim)`。

```python
import tinytorch.nn as nn
from tinytorch import NdArray, Tensor

emb = nn.Embedding(num_embeddings=1000, embedding_dim=128, padding_idx=0)
idx = Tensor(NdArray([[1, 2, 3], [4, 5, 0]]), requires_grad=False)
y = emb(idx)                   # shape: (2, 3, 128)
```

### 6.8.2 `Conv2d`

```python
Conv2d(in_channels, out_channels, kernel_size, stride=1, padding=0, use_bias=True)
```

- 卷积核形状 `(out_channels, in_channels, kernel_size, kernel_size)`，采用 Kaiming 均匀初始化（无显式 `nonlinearity`，走默认 `leaky_relu`）；
- 偏置形状 `(out_channels,)`，初始化为 0；
- 输入形状必须是 4D `(batch_size, in_channels, height, width)`，且 `in_channels` 必须与层定义一致，否则抛 `ValueError`；
- 实际卷积计算由 `autograd.ops.conv.Conv2d` 算子完成；
- ⚠️ **仅支持正方形核**（`kernel_size` 是单个 `int`）和**相同 `stride` / `padding`**（也是 `int`，不支持 `(h, w)` 元组形式）。

## 6.9 序列模型：`RNN` / `LSTM` / `GRU`

三者共用基类 `RNNBase`（模板方法模式），子类只需实现 `_cell_forward`，复用输入校验、逐时间步循环、状态收集等骨架。

### 6.9.1 公共签名与输入约定

```python
RNN (input_size, hidden_size, use_bias=True)
LSTM(input_size, hidden_size, use_bias=True)
GRU (input_size, hidden_size, use_bias=True)
```

- 输入形状统一为 `(batch_size, seq_len, input_size)`；`input_size` 不匹配会抛 `ValueError`；
- 权重使用 `U(-1/sqrt(hidden_size), 1/sqrt(hidden_size))` 均匀初始化；
- `use_bias=False` 时所有偏置为 `None`。

### 6.9.2 返回值差异

| 类 | 返回 | 备注 |
|----|------|------|
| `RNN` | 一个 `Tensor`，形状 `(batch, seq_len, hidden_size)` | 即所有时间步的隐藏状态 |
| `LSTM` | `(h_all, c_final)`：`h_all` 形状 `(batch, seq_len, hidden_size)`，`c_final` 形状 `(batch, hidden_size)` | `c_final` 是**最后一步**的 cell state |
| `GRU` | 一个 `Tensor`，形状 `(batch, seq_len, hidden_size)` | 同 `RNN` |

### 6.9.3 单元公式（与源码一致）

**RNN**：

```
h_t = tanh(x_t @ W_ih.T + h_{t-1} @ W_hh.T + b)
```

**LSTM**（四门：i / f / g / o）：

```
i_t = sigmoid(x_t @ W_ii.T + h_{t-1} @ W_hi.T + b_i)
f_t = sigmoid(x_t @ W_if.T + h_{t-1} @ W_hf.T + b_f)
g_t =    tanh(x_t @ W_ig.T + h_{t-1} @ W_hg.T + b_g)
o_t = sigmoid(x_t @ W_io.T + h_{t-1} @ W_ho.T + b_o)
c_t = f_t * c_{t-1} + i_t * g_t
h_t = o_t * tanh(c_t)
```

**GRU**（三门：r / z / n）：

```
r_t = sigmoid(x_t @ W_ir.T + h_{t-1} @ W_hr.T + b_r)
z_t = sigmoid(x_t @ W_iz.T + h_{t-1} @ W_hz.T + b_z)
n_t =    tanh(x_t @ W_in.T + r_t * (h_{t-1} @ W_hn.T) + b_n)
h_t = (1 - z_t) * n_t + z_t * h_{t-1}
```

### 6.9.4 可选的初始状态

`forward(input, initial_states=None)`：

- `RNN` / `GRU`：`initial_states` 是单个 `Tensor`，形状 `(batch, hidden_size)`；
- `LSTM`：`initial_states` 是 `(h_0, c_0)` 元组；
- 省略时统一初始化为全零 Tensor（`requires_grad=False`）。

## 6.10 `MultiHeadAttention`

```python
MultiHeadAttention(embed_dim, num_heads, dropout=0.0)
```

- 要求 `embed_dim % num_heads == 0`，否则抛 `ValueError`；
- 内部 `head_dim = embed_dim // num_heads`；
- 含四个 `Linear(embed_dim, embed_dim, use_bias=True)`：`W_q`、`W_k`、`W_v`、`W_o`；
- `forward(query, key=None, value=None, mask=None)`：
  - `query` 形状 `(batch, seq_len, embed_dim)`；
  - 未传 `key` / `value` 时默认复用 `query`（自注意力）；
  - `mask` 可选，若提供会传给底层算子 `ScaledDotProductAttention`；
- `dropout` 参数透传到底层算子 `ScaledDotProductAttention`，实际是否生效取决于 `self.training`。

示例：

```python
import tinytorch.nn as nn
from tinytorch import NdArray, Tensor

attn = nn.MultiHeadAttention(embed_dim=64, num_heads=8, dropout=0.1)
x = Tensor(NdArray.randn((2, 10, 64)))   # (batch=2, seq=10, dim=64)

# 自注意力
y = attn(x)                      # (2, 10, 64)

# Cross-attention
ctx = Tensor(NdArray.randn((2, 15, 64)))
y2 = attn(x, ctx, ctx)           # query 来自 x，key/value 来自 ctx
```

## 6.11 自定义层模板

```python
from tinytorch.nn import Module, Parameter
from tinytorch.nn import init
from tinytorch.ndarr import NdArray


class Affine(Module):
    """自定义层：y = x * scale + shift（逐元素，无广播以外的变换）"""

    def __init__(self, num_features: int):
        super().__init__()
        self.num_features = num_features
        self.scale = Parameter(NdArray.ones((num_features,)), name='scale')
        self.shift = Parameter(NdArray.zeros((num_features,)), name='shift')

    def forward(self, x):
        return x * self.scale + self.shift

    def __repr__(self):
        return f"Affine(num_features={self.num_features})"
```

自动获得的能力：

- `layer.parameters()` / `layer.named_parameters()` 能找到 `scale` 与 `shift`；
- `Sequential(..., Affine(32), ...)` 可以直接组合；
- `state_dict()` / `load_state_dict()` 免费支持；
- `train()` / `eval()` / `zero_grad()` 递归生效。

## 6.12 使用约束与注意事项

- **输入必须是 `Tensor`**：所有层的 `forward` 都期望 `Tensor`，不能直接传 `NdArray`。
- **`Conv2d` 限制**：`kernel_size` / `stride` / `padding` 只支持 `int`；`in_channels` 必须匹配。
- **`LayerNorm` 的 `normalized_shape`**：必须等于输入末尾若干维度，不匹配会抛 `ValueError`。
- **`Dropout` 的模式敏感性**：切换到 `eval()` 后会变成恒等映射；评估完记得切回 `train()`。
- **`ModuleList` 不执行 `forward`**：必须在外层模块的 `forward` 里手动遍历。
- **`Embedding` 的输入 dtype**：实际走索引，索引值必须在 `[0, num_embeddings)`，越界行为由底层 `EmbeddingLookup` 算子决定。
- **循环网络的性能**：`RNN` / `LSTM` / `GRU` 在纯 Python 下逐时间步跑 Python 循环，长序列会非常慢。
